Informazioni Sistema

Questa sezione genera le assegnazioni automatiche degli appartamenti ai cleaner selezionati dal file sel_cleaners.json.

Le assegnazioni vengono create in base a:

  • Appartamenti con check-in alle 14:00 o small_equipment = true (priorità 1)
  • Distanza massima di 800 metri tra appartamenti consecutivi
  • Sequenze di mediamente 3 appartamenti per cleaner
  • Ottimizzazione dei percorsi tramite Google Maps

Prerequisito: Seleziona prima i cleaner nella sezione "Genera convocazioni"

Opzioni di Assegnazione

Il sistema assegnerà automaticamente gli appartamenti in base all'algoritmo di ottimizzazione.

Permette di assegnare manualmente specifici appartamenti a cleaner selezionati.
